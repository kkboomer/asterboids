# Asterboids
---
A expansion of the boids algorithm combined with the classic game of *asteroids*

### How to run:

In your terminal, run:
```Python
uv run asterboids
```
### Controls
- L/R arrow: rotate
- UP arrow: forward
- Space: Shoot
